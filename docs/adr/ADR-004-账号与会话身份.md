# ADR-004：账号与会话身份（P3 教务登录）

- 状态：已采纳（为 P3 预先定界）

## 背景

实施方案要求：直接 HTTP 登录 + 官方网页备用流程、Cookie 轮换/失效处理、
成绩按账号与学期分区；Android 首版不新建课表云后端，已有账号/设置服务端
只做评估、不默认接入。

## 决策

1. **身份锚点是"连接"不是"账号"**：`Timetable.connectionId` 标识一次教务绑定
   （学校 + 会话主体）。本地多课表（LOCAL）与绑定课表（YGU）并存，
   `source` 字段区分；仅 LOCAL 可删除，YGU 课表随绑定生命周期管理。
2. **会话凭据**只存安全存储（EncryptedSharedPreferences/Keystore 评估后定），
   DataStore 只放非敏感偏好，**禁止出现密码/Cookie 明文**；SavedStateHandle
   不塞 Cookie/整份 HTML。
3. **会话失效**是数据状态不是崩溃：UiState 需含"需要登录"态；失效后保留
   本地已同步数据，引导重登。
4. 成绩缓存按（连接, 学年学期）分区，标注查询时间；不把缓存伪装成刚查询成功。
5. 学校客户端实现放 `platform:android`（或独立 data 子域），经领域端口
   （登录/同步/成绩）暴露，UI 不感知 OkHttp/Cookie 细节。

## 后果

- P2 的多课表/复制/删除已按 source 区分能力，接入时无需改模型；
- 账号切换 = 连接切换，绑定课表隔离，手动课表永不被同步覆盖。
