# 课表页学年学期浏览：实现与验证

日期：2026-11-01。GPT 6.1 Sol 编写代码，主代理独立审查并执行最终联合验证。

## 使用方式

点击课表页顶部的周标题或学期日期副标题，打开“选择学期与周次”底部面板；先从学校返回的列表中选择学期，再在下方选择周次。主页不再单独展示“学校学期”操作行。面板在学期读取、切换和失败时保持打开；选择周次后关闭。面板内容整体滚动，以适应窄屏和大字体。浏览支持周选择、左右翻周、课程详情、下拉刷新和“返回当前课表”。学期之间保留本次浏览的周次；返回当前课表恢复原周次。

浏览显示学校快照，缓存按学校、账号主体与学期隔离，保存在私有 no-backup 目录。只接受学校列表及其缓存选项，不提供任意学期输入。失败保留已有快照；重新打开应用可读取缓存。

下拉刷新先退出历史学期浏览，回到当前正在使用的课表及按开学日期计算的本周，同时在后台同步学校数据。页面播放 300ms 淡入与 8dp 位移过渡，在动画结束且当前周分页确认显示后提示“本地课表刷新成功”；转圈不等待教务网络完成。面板中的“重试”仍读取已选学期；“返回当前课表”按钮仍恢复原先周次。刷新结束不会覆盖等待期间用户新选的周次。

历史浏览为只读，不调用同步提交或切换全局当前课表，不修改今日页、提醒、日历或桌面组件的数据来源。本地临时调课不合并进学校浏览快照。仅精确匹配当前连接和学期的本地学期元数据可提供已知开学日期；未知日期显示“日期待设置”，隐藏计算用日期、今日标记与考试。

## 主代理审查与修正

- 顶部周标题和学期日期副标题共用原有点击区域，统一打开学期与周次面板；移除独立操作行和不再使用的顶栏扩展槽，保留原有玻璃采样、安全区与空白命中拦截。
- 浏览学期尚在加载或报错时也禁止新增、编辑、删除、拖动和临时调整；保留详情关闭与周次选择。
- 独立账号、学期和列表请求版本防止迟到响应覆盖新状态；同账号会话过期保留已显示的缓存并提供登录入口。
- 浏览投影在后台线程计算，投影异常只影响本次选择，重试和返回仍有效。
- 缓存写入采用同目录临时文件、同步写入与原子替换；缓存损坏、身份不符或版本不支持视为未命中。缓存不含凭据或原始学校响应。
- 仅确认星期表头、连续节次及完整空单元格的表格可作为无课程结果；解析异常仍失败，原教务同步继续拒绝空结果写入。

## 切换卡顿优化与选择面板

- 源码确认网络调用返回后的学校页面解析原先在主线程继续运行。现在整个学期列表和课表读取调用都在后台执行，包含返回后的解析；状态更新及迟到响应检查仍由原控制器处理。
- 将整学期投影与周次、加载状态和时钟更新分开。最多缓存 3 份投影；实际课程、时间段、开学日期和账号变化会重新计算，响应时间与原始 HTML 变化不会触发重建。
- 课程按日期预先分组，整学期课程密度只计算一次。回归检查中，同一份 20 周课表翻周时额外的周网格构建次数由 20 降至 0；保留跨日更新、切换上下文和真实数据变化的失效检查。这是计算次数证据，不代表真机帧率测量。
- 面板与详情弹层分别管理生命周期。换学期时保留面板，仅显示当前所选学期对应的周次；网络或投影错误均可在面板内重试。选择周次或回到本周后关闭，返回当前课表后可继续选周。
- 窄屏、大字号时整个面板可滚动，避免学期控件与周次列表相互挤压。7 项定向 UI 测试覆盖入口、加载和错误保持、重试、选择关闭及 320dp / 1.6 倍字体下的末周访问。

## 下拉刷新回到本周：后续验证

下拉手势调用独立的 `pullRefresh()`：取消历史学期请求、清除手动周次选择，再直接刷新当前课表。当前课表刷新使用独立私有方法，避免退出浏览后异步状态尚未传播而误走历史学期刷新。选择面板继续使用原有刷新与重试回调。
