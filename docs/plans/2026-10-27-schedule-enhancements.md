# 课表增强实施与审查

用户授权：由 GPT-6.1 Sol 实现，主代理独立审查。以当前未提交工作区为基线，保留已有修改，不提交、不推送、不操作设备。鸿蒙及参考仓库只读。

## 1. 有效课表与显示正确性

- 周视图按当前课表的分组、星期和轮换规则逐日选择生效课表，与今日页语义一致；显式指定课表的导出/组件查询保持其原有语义。
- 周次点阵与调课冲突提示读取叠加取消、移动、临时整天后的有效实例。
- 课程冲突按照实际区间组成重叠组并分列，保留每条课程及详情入口；非本周课程不能抢占真实课程的展示优先级。
- 阳光学院官方课表使用 11 节展示，非教务课表继续根据作息与课程扩展。
- 对关键规则补充行为测试，包括跨起始节重叠、跨周调课、取消及自动选表。

## 2. 补齐显示偏好

- 非本周课程显示开关、星期/日期表头顺序。
- 偏好贯通 DataStore、JSON/设置备份，旧数据默认兼容；只改变呈现。

## 3. 课表交互与扩展

- 跟手周分页，保持上一周/下一周/周选择/回到本周和刷新入口。
- 长按课程进入拖拽调课；落点确认后复用既有临时调整接口，支持跨周暂存与取消。
- 现有考试数据叠加到周网格，课程和考试可区分，考试按日期/钟点定位；缺失时间不伪造。
- 可选午休分隔，从作息时间推导，不硬编码其他学校的时间。
- 宽屏提供常驻周次选择侧栏，窄屏保留现有周选择入口。

## 4. 设置预览与详情

- 设置页显示真实课表预览；竖屏上下、宽屏左右布局，预览与正式课表共享绘制逻辑。
- 多课程详情使用左右滑动分页和页指示器，保留现有编辑/复制/删除/调课能力。原详情未提供提醒按钮，本轮不新增提醒入口。
- 优先抽取拾光的小型 Compose 组件；如复制或改编源码，保留 Apache-2.0、原作者署名及修改声明，不能引入其数据库/依赖注入体系。

- 每阶段由实现代理自检，主代理先核对需求覆盖，再检查代码质量、边界与已有改动保留。

- 验证记录区分源码、单测、构建和真机结果；不把编译通过称为手势、视觉或提醒送达验收。
