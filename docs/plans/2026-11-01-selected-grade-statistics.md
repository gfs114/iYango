# 成绩自选算分

用户已选择只实现自选课程算分，其他参考功能不实施。GPT 6.1 Sol 编写代码，主代理独立审查；保留现有未提交工作，不操作设备、不请求学校接口、不提交或推送。

## 交互与口径

- 成绩统计卡增加“自选算分”入口。进入后显示课程复选框，点击整条记录切换勾选，提供全选、清空和退出。
- 自选统计只计算所选记录；未选择时均分和绩点显示空值。退出恢复原来的整体统计与详情点击行为。
- 复用现有 `GradeStatisticsCalculator` 和“统计包含选修课”设置。显示已选条数、实际纳入与排除条数、纳入统计学分；纯文本成绩和零学分不参与，绩点只使用学校返回值，重修补考按记录处理，不按课程名合并。
- 选择仅存在于本次页面状态，不改学校成绩或数据库。排序、草稿筛选、标记已读及刷新失败保留选择；账号、确认范围或成功缓存快照变化清空选择。新快照导致清空时说明原因。
- 以当前快照内的数据库行 ID 区分记录，结合账号、范围和快照版本校验回调。收到新成绩时数据库会重建记录，旧勾选不得套用到新行。
