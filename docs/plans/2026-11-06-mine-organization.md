# “我的”页面功能整理

用户要求将相关功能收纳到二级页面，并已选择首页保留“课程管理、教室查询”两个快捷入口。

后续样式确认：首页不显示“常用功能”小标题和底部 iYango 字样；“功能与设置”下各入口只保留名称、图标和进入箭头，不显示描述小字。分类页仍保留完整功能说明。

账号卡后续确认：删除首字头像；无账号或已退出时显示“登录教务账号”，不显示“同学”或已退出账号缓存的姓名。已连接显示真实姓名（缺失时回退脱敏账号），验证中、过期、连接失败使用各自状态说明。

参考了用户提供的两个文件夹，内容仅作为实现参考：

- `G:/code/deepseek/wakeup-re/code/sources/com/suda/yzune/wakeupschedule/aaa/widget/MineNewUserLoginView.java` 的 `refreshUnLoginUI` 与 `values/strings.xml`：未登录显示“立即登录”，登录后切换真实账号资料。
- `C:/Users/32773/Desktop/campus-ui-reference/3-sachet/lib/widgets/utils_widgets/nav_drawer.dart` 的 `MyUserAccountDrawerHeader`：将未登录提示与真实教务身份区分，并保留整块账号入口。
- `C:/Users/32773/Desktop/campus-ui-reference/1-XJAU-Helper/entry/src/main/ets/view/MineView.ets` 的 `avatarCard`：头像隐藏时取消左侧头像占位，文字直接对齐卡片内边距。

沿用本项目 GlassSurface 和现有账号状态订阅，没有复制参考项目的账号、头像或退出逻辑。

## 信息结构

| 位置 | 功能 |
| --- | --- |
| 首页账号卡 | 显示当前教务账号，点击进入账号页 |
| 首页常用功能 | 课程管理、教室查询 |
| 课程与课表 | 课程管理、我的课表、学期管理、考试安排 |
| 教务服务 | 教务账号、教室查询、同步记录 |
| 外观与布局 | 全局课表显示、壁纸与背景、主题色、深浅色、自定义色、染背景、玻璃底栏遮罩、默认启动页、导航布局、切换动画 |
| 数据与备份 | 导入导出、设置备份与重置 |
| 首页其余入口 | 提醒与日历、关于与反馈（直接进入原有二级页面） |

选择分类页而非折叠首页：首页不再包含设置控件，信息量更少；完整功能清单保留在分类页。用户确认的两个快捷入口与分类页共用原有目标路由。没有新增备份或同步机制，也没有改动现有设置数据。

## 实现约束

- 分类页是主导航栈的全屏页面，隐藏首页底栏；进入具体功能后，返回先回到分类页，再回“我的”。
- 保留原有外部快捷方式和通知路由。外观页沿用 ThemeViewModel / WallpaperViewModel 的状态与写入回调，全局课表显示保留 `perTimetable=false`。
- 保留账号状态和首页滚动位置，标题继续采用 GlassScaffold / GlassTopBar。
- 将主题色和模式选项改为 FlowRow，给选项足够的触摸高度，窄屏/大字号允许换行；设置开关提供明确辅助功能标签。
- 不迁移数据库，不重置偏好，不提交或推送。已有未提交改动单独保存哈希核对。
